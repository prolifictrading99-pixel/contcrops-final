# ContCrops 🌿 - تواصل - تبادل - نمو مستدام

منصة المحاصيل والمجتمع الزراعي - السوق الزراعي الذكي

## المميزات
- 🏪 سوق محاصيل (فريش/مجمد/مجفف/محطات فرز وتعبئة/مستلزمات زراعة/مستلزمات انتاج/نقل ولوجيستك)
- 👥 مجتمع الزملاء + متابعة + مراسلة
- 💬 رسائل مباشرة بين المزارعين
- 📈 أسعار احترافية بجدول وتغيرات يومية
- 🔐 كل حساب باسمه (ليس أحمد المزارع ثابت)
- 🌿 شعار C أسود أخضر - تواصل تبادل نمو مستدام

## التشغيل
```bash
npm install
npm run dev
```

## Supabase
أنشئ ملف `.env.local`:
```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

ثم نفذ `supabase/schema.sql` في SQL Editor

## التصميم
- Next.js 14.2.5
- Tailwind CSS
- Supabase
- نفس التصميم rounded-[24px] بدون تغيير
